# Changes

## 5.1.0

- Direct Session History and Statistics sidebar destinations; visible app version
  and About information identify the running copy.
- All-time, recent-period and custom-date history filters, plus tag include/exclude
  filters shared with Statistics.
- Centered session table; completion notes appear only in a clearly labeled,
  resizable selected-session pane.
- Add tags when finishing/editing sessions; right-click selected rows to add or
  remove tags in bulk. Tag editing is separate from filtering.
- Distraction Dump starts collapsed in the session editor.
- Durable JSON saves, rolling backups, failed-save retention, and regression tests
  for existing records. Save Session and Quit retains work notes.
- Separate startup, navigation, Statistics, calculations, defaults and history data
  operations. Consistent formatting, import cleanup, Ruff configuration, and removal
  of committed Python bytecode. User records, media and branding are retained.
